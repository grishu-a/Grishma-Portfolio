# Grishma Amatya - Portfolio

Personal portfolio of **Grishma Amatya**, a product and project delivery professional in fintech and payments, based in Sydney.

**Live site:** https://grishma-portfolio-ruddy.vercel.app

## What's inside

- **Featured projects** from Fonepay, Nepal's leading payment network - Alipay+ cross-border payments, Fonepay Circle (PayID-style send, request and split) and a new Dispute Management System
- **Case studies** for each featured project, covering the problem, my role from initiation to deployment, challenges and outcomes
- Experience, recommendations, skills, education and certifications

## Built with

- [Next.js](https://nextjs.org) (App Router) and React, written in TypeScript
- [Tailwind CSS](https://tailwindcss.com) with light and dark themes
- Deployed on [Vercel](https://vercel.com), with Vercel Web Analytics
- Accessibility and performance checked with Lighthouse (100 accessibility, 99-100 performance)

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Site content lives in `src/lib/data.ts`.
